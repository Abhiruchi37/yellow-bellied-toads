# Throat + Belly Photo-Identification Pipeline

## Overview

This section is reserved for the **combined throat-and-belly** contribution of the Yellow-Bellied Toad photo-identification project.

The aim is to investigate whether combining both ventral regions improves individual re-identification, particularly when one region is partly unclear or unavailable.

## Planned Structure

1. Dataset preparation
2. Throat + belly annotation
3. Segmentation / region extraction
4. Standardized combined inputs
5. Re-identification
6. Evaluation
7. Comparison with throat-only and belly-only results
