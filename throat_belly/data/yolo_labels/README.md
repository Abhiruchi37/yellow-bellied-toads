# YOLO Segmentation Labels

This folder contains the YOLO segmentation labels generated from the manually created LabelMe polygon annotations.

The labels correspond to the combined `belly_throat` region.

The dataset contains:

- 80 training labels in `train/`
- 20 validation labels in `val/`

Each `.txt` file contains the normalized polygon coordinates used by YOLO for segmentation training.

The corresponding image dataset is not duplicated in this repository.
