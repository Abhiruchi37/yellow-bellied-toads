# Belly + Throat Identification

This folder contains the results and documentation for the individual identification stage using the combined belly + throat crops.

## Identification Method

The cropped belly + throat images generated by the YOLO segmentation stage were used as input for individual identification.

The identification method uses:

- SuperPoint for detecting keypoints and extracting local image features.
- LightGlue for matching the SuperPoint features between two images.

The identification dataset contained 200 cropped belly + throat images.

Each unique pair of images was compared, resulting in 19,900 image-pair comparisons.

## Matching Score

For each image pair, the matching score was calculated as:

`Combined Score = Number of Matches × Average Match Confidence`

The score combines the number of matched features with the confidence of those matches.

## Files

The identification code is available in:

`../scripts/Belly_Throat_SuperPoint_LightGlue_Identification.ipynb`

The identification result files are stored separately in this folder.

## Related Workflow

The complete workflow is:

Original image → YOLO belly + throat segmentation → Crop generation → SuperPoint feature extraction → LightGlue feature matching → Identification results
