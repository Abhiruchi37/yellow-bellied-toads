# Wild-ID Results

This folder contains the result file from the Wild-ID comparison performed using the belly + throat cropped images.

## Wild-ID

Wild-ID was used as an additional identification method for comparison with the SuperPoint + LightGlue approach.

The cropped belly + throat images produced by the YOLO segmentation stage were used as input to Wild-ID.

Wild-ID calculates similarity scores between images and presents candidate matches for manual verification.

## `confirmed-matches.txt`

This file contains the Wild-ID matching decisions and includes information such as:

- image filename
- matched image filename
- candidate rank
- Wild-ID similarity score
- images for which no match was confirmed

The file was generated by Wild-ID during the matching and manual verification process.

## Repository Note

The Wild-ID application files, internal binary database files and the complete set of cropped input images are not duplicated in this repository.
