# Throat-Only Photo-Identification Pipeline

## Overview

This section is reserved for the **throat-only** contribution of the Yellow-Bellied Toad photo-identification project.

The aim is to investigate whether the throat pattern alone can provide useful information for individual re-identification.

## Planned Structure

1. Dataset preparation
2. Throat annotation
3. YOLO segmentation
4. Throat crop extraction
5. Re-identification
6. Evaluation

## Files

The group member responsible for the throat-only experiment can add the final notebook under:

```text
throat/notebooks/throat_pipeline.ipynb
```

Results and example images can be added after the final experiments are completed.

> This README intentionally does not report numerical results until the throat-only experiments are finalized.
