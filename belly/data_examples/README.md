# Data Examples

This folder is only for a very small sample showing the expected input/data format. Do **not** upload the complete research dataset here.

Suggested contents:
- 1–2 representative A-pond images (only if sharing is permitted)
- 1–2 representative H-pond images
- 1–2 example YOLO polygon label `.txt` files
- a small example metadata/config file if needed

The complete dataset remains in Google Drive; see the main `belly/README.md`.
