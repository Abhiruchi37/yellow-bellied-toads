# Extracted Belly Crops

This folder contains selected examples of the final belly crops produced by the trained YOLO segmentation model.

For each image, the predicted belly segmentation mask was used to isolate the belly region and create a tight crop around the detected area. These crops were subsequently used as input for the re-identification experiments.

The final model successfully generated belly crops for 192 of the 199 A-pond images.

The complete image collection is stored externally due to its size.
